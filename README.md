# PokedexApp

Este é um aplicativo simples de Pokédex desenvolvido com React Native e Expo para fins didáticos no curso de Desenvolvimento Mobile do IFSP.

---

## Aviso sobre `node_modules`

A pasta `node_modules` foi incluída neste repositório apenas temporariamente para fins acadêmicos.

Em projetos reais, essa pasta não deve ser enviada ao Git, pois:

- É muito pesada
- Pode ser recriada com `npm install`
- Costuma ser ignorada por padrão no arquivo `.gitignore`

---

## Instalação do projeto

Caso você prefira clonar o projeto e instalar as dependências localmente, siga os passos abaixo.

### 1. Clone o repositório

bash
git clone https://github.com/MirandaaaDev/PokedexApp.git
cd PokedexApp

### 2. Instale as dependências
- Certifique-se de ter o Node.js e o Expo CLI instalados
  
npm install
npx expo start
